# D10 design round: sources read, and a verdict on each

Date: 2026-09-27. Companion to [DESIGN.md](DESIGN.md). All prior material
was read as evidence to weigh, not as authority. Where a source makes a claim
about code, the claim was checked against the code at this branch
(`feature/kernel-package-extraction`, HEAD `41c30ca0d` plus the uncommitted
STATUS/SPEC edits) before DESIGN.md relied on it.

Verdicts: **adopt** (DESIGN.md uses it as is), **revise** (the idea, changed),
**drop** (considered and rejected), **context** (background only).
