# Revised Template Implementation Plan

## Overview

Based on analysis of existing FINN templates, this plan converts the current `$VARIABLE$` syntax templates to Jinja2 format for the new unified codegen system.

## Existing Template Analysis

### **HLS Templates** (from `src/finn/custom_op/fpgadataflow/templates.py`):
- `docompute_template` - Single node execution
- `docompute_template_timeout` - Single node execution with timeout  
- `ipgen_template` - CPP file for IP generation
- `ipgentcl_template` - TCL script for IP generation
- `ip_package_tcl` - IP packaging TCL

### **RTL Templates** (from `finn-rtllib`):
- `thresholding_template_wrapper.v` - Thresholding RTL wrapper
- `swg_template_wrapper.v` - SWG RTL wrapper

## Template Conversion Strategy

Convert existing `$VARIABLE$` syntax to Jinja2 `{{ variable }}` syntax while preserving all functionality.

## Phase 5: Template Engine Backward Compatibility

### **Update Template Engine** (`template_engine.py`)

Add backward compatibility method for existing `$VARIABLE$` syntax:

```python
def render_legacy(self, template_content: str, replacements: Dict[str, Any]) -> str:
    """
    Render using legacy string replacement method.
    
    This method provides backward compatibility with existing RTL
    operations that use simple string replacement (e.g., $KEY$ -> value).
    """
    result = template_content
    for key, value in replacements.items():
        # Handle both $KEY$ and KEY formats
        placeholder = f"${key}$" if not key.startswith('$') else key
        if not placeholder.endswith('$'):
            placeholder += '$'
        result = result.replace(placeholder, str(value))
    return result
```
